Iframe exemplar frame document

This document is a frame source for the iframes exemplar, which embeds it in a same-origin frame, reproduces it in a srcdoc frame, and embeds an identical copy in a cross-site frame. It is also registered as a page of the “Kilotest exemplars” site, so testing it directly provides the unframed baseline: the defects a rule engine reports here but fails to report in a framed copy mark an engine that cannot reach the frame contents. Except for the deliberate defects below, this document is defect-free, so every reported violation can be attributed to an intended defect.
