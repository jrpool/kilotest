Iframe exemplar

This exemplar page ascertains which rule engines, if any, can test the descendants of iframes. It embeds three frames containing identical defect sets: a same-origin frame, a srcdoc frame, and a cross-site frame served by GitHub Pages from a different registrable domain. The frame elements themselves are defect-free, so every violation attributed to an element inside a frame comes from an intended defect in its document.

The same defects also appear in this top-level document, so an engine that reports them here but not inside a frame is demonstrably failing at the frame boundary. In addition, each frame document is registered and tested as its own page, providing the unframed baseline for comparison across reports.
