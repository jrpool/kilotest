Iframe exemplar

This exemplar page ascertains which rule engines, if any, can test the descendants of iframes. It embeds three frames containing identical defect sets: a same-origin frame, a srcdoc frame, and a cross-site frame served by GitHub Pages from a different registrable domain. The frame elements themselves are defect-free, so every violation attributed to an element inside a frame comes from an intended defect in its document. Each frame document is also registered and tested as its own page, providing the unframed baseline: a rule engine that reports the defects in a directly tested frame document but not in its framed copy cannot reach the frame contents.
