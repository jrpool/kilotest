Kilotest Exemplars: about this site

Kilotest Exemplars is a metasite: a special website created as an adjunct to Kilotest.

The pages of this site contain deliberate defects. The purpose of each page is to help you assess how well Kilotest, and the rule engines that it uses for testing, do their job.

Each exemplar page contains defects of only one kind. So, that page will reveal which rule engines report defects of that kind—and which do not.

To examine the exemplar pages, go to Kilotest home page and select Which websites have been tested?. Then select Kilotest Exemplars. The list of links will take you to the test results and links to the pages themselves.

Note: What are the main issues? compiles statistics from all tested pages—except the exemplar pages.
