Kilotest: Privacy policy

This policy applies to the Kilotest web site, API, and MCP server at kilotest.com, and does not apply to any other deployment of Kilotest. Kilotest does not require an account, does not ask for your name or email address, and does not use advertising or tracking cookies.

What Kilotest collects

  • Request logs. For every request, Kilotest and its reverse proxy log the IP address, user agent, HTTP method, path (without any query string), response status, and time. This applies to requests made by AI platforms on your behalf as well as to requests from your browser.
  • Submissions. If you request testing of a web page, request retesting, comment on a tutorial, or request a feature, Kilotest stores what you submit, such as the URL of the page and the text of the comment.
  • Usage counts. Kilotest keeps aggregate counts of page views, MCP tool calls, and API operations. The counts are not linked to any person.

How Kilotest uses the information

Request logs are used to keep the service available and to detect abuse. Submissions are reviewed by the Kilotest maintainer and used to run tests and improve Kilotest. Kilotest does not sell information, use it for advertising, or build profiles of users.

What is public

Test reports are public. A report contains the URL that was tested and the test results, and anyone can retrieve it. If you control a web page and Kilotest gets a request from you (or anybody else) to test it, the report will be public. Kilotest does not need or request passwords or other secrets.

Who else receives information

Kilotest sends its maintainer an email notice, through the transactional email service Resend, when a submission arrives. The notice contains the submission. The site is hosted on a server of Vultr, and the site root is checked periodically by UptimeRobot, which receives no user data. Kilotest discloses information to others only if the law requires it.

How long Kilotest keeps information

Request logs are rotated and deleted automatically. The application log keeps about 14 files of up to 20 MB each, and the proxy log keeps at most 10 files of up to 50 MB each for at most 30 days. Reports and submissions are kept until the maintainer deletes them.

Your choices

To ask what Kilotest holds about you, or to ask for deletion of a submission or report about a web page that you own, email info@kilotest.com and identify the item.

Changes and contact

Changes to this policy are recorded in the public repository. Questions can be sent to info@kilotest.com.
